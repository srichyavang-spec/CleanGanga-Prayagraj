# CleanGanga-Prayagraj

## Current Goal
Build a pollution hotspot detection system for Prayagraj river monitoring data.

## Core Questions
1. Where is pollution occurring?
2. How severe is the pollution?
3. Is the pollution persistent?
4. What parameters are responsible?
5. What possible causes can be identified from the available evidence?

## Pollution Classification
Pollution classification will use fixed environmental thresholds rather than thresholds learned from the dataset.

## Priority
Persistent pollution receives higher importance than isolated pollution spikes.
